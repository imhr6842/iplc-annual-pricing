## IPLC 年付到底在买什么

IPLC（International Private Leased Circuit）指的是点对点的国际私有专线。和普通公网 VPN、机场代理不同，IPLC 在运营商骨干网内部走专用通道，延迟低、抖动小、IP 干净，适合业务里有"必须稳定"诉求的场景，比如跨境电商独立站、Shopee/TikTok 直播推流、海外 SaaS 后台操作等。

年付实质上是把支付周期拉长，一次性付清 12 个月。通常月付最难拿到底价，季付开始有折扣，年付往往是折扣最深、也最考验平台运营稳定性的一个档位——毕竟你押的是一笔不小的钱进去。

## 年付怎么下单更划算

Mkcloud 在年付上的折扣力度，主要来自三类：

1. **官方活动**。从过往公告看，年中 618、新春、周年庆、双旦这几个节点会出现限量年付优惠码，比如 MK-8.8（流量计费产品循环 8.8 折）、MK-7.8（独享带宽产品首月 7.8 折）、MK-IPLC-WELCOME（沪美 IPLC 9 折循环折扣）等。优惠码目前都标注为活动期有效，长期可用需以下单时实时确认。
2. **季付 / 年付本身的折扣**。以沪港 IPLC 1TB 档为例，月付 288 元，季付 864 元，年付 3456 元，年付单月折算约等于月付的 9.999 折左右、再叠加优惠码再降一档。
3. **拉新 / AFF 奖励**。官方拉新奖励为一次性 10% 返佣 + 额外 20Mbps 峰值带宽，最高可叠加至 200Mbps，适合自用加上顺手推用户。

> 实际付款之前一定登录后台看一下当前活动页面，活动码过了截止时间是不能循环使用的。

## 流量计费 vs 独享带宽：年付之前先选清楚

同一个业务在不同计费方式下，年付预算能差出一倍以上。

- **流量计费（共享带宽）**：带宽是峰值共享，月付便宜、年付更划算，适合流量稳定、能预估每月用量的业务。
- **独享带宽**：带宽独占、流量无限，月付 650 元起步，适合直播推流、实时数据同步等需要稳定带宽、不想被共享用户抢资源的场景。

业务是"后台操作 + 数据传输"选流量计费就够；业务里有推流、对延迟稳定有硬要求，独享款更省心。

## 几个容易踩坑的点

- **省级白名单限制**。Mkcloud 全部专线产品都默认绑定一个省份的来源 IP，开通后只能修改到另一个省份，没法跨多个省份共用一台机器。
- **退款只认质量问题，不支持跨地区更换**。一旦按月/季/年付下单，开通后换线路就只能重买。
- **付款路径单一只支持支付宝**。需要企业网银、USDT、对公转账的话要提前沟通。
- **不支持动态换地区、不支持机场 / 回国等灰色用途**。平台是按正规跨境业务设计的，买之前先确认自己的使用场景在合规访问的目标范围之内。

## 常见问题

**月付、季付和年付之间，建议怎么选？**
先用月付跑 1–2 个月，确认实际流量、延迟、IP 质量都达到预期，再切到季付或年付拿折扣。年付适合预估用量稳定且计划长期使用同一线路的人。

**沪港、沪日、沪美怎么看哪条合用？**
业务目标国家决定线路。香港方向走沪港或广港、日本方向走沪日、美区走沪美。同一档配置下，沪美比沪港贵，主要差距来自物理距离。

**优惠码过了活动期还能用吗？**
不能。活动期内的循环折扣码在订单生命周期内仍然有效，但已经结束的活动再次下单需要等下一轮活动。

**中途改了使用省份怎么办？**
可以，但要在后台提交修改，且只能改成另一个省份，没法支持两省并存。
